# Runnelon

**Traffic flows better here.**

Runnelon is an open-source reverse proxy and API gateway built with Rust and powered by Cloudflare Pingora.

We're building networking infrastructure designed to be fast, reliable, and simple to operate.

### What we're building

- High-performance HTTP/HTTPS reverse proxy
- Dynamic routing and load balancing
- Docker-native service discovery
- TLS termination and secure defaults
- Metrics, observability, and developer-friendly configuration

### Project status

🚧 **Early development**

Runnelon is under active development. APIs, configuration formats, and planned features may change.

### Our principles

**Performance by design.** Build on proven networking foundations.

**Simple by default.** Make deployment and operations approachable.

**Open by nature.** Develop transparently and welcome community contributions.
